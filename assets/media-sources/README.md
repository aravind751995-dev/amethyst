# Amethyst local media

Hero videos and destination images are downloaded into this directory by GitHub Actions from free-stock sources.

Videos:
- Home: Pexels Chennai aerial footage
- Tours: Pixabay AI-generated waterfall footage
- Yatras: Pixabay India temple journey footage
- Retreats: Pixabay Sikkim monsoon road-trip footage
- Surprises: Pixabay AI-generated birthday/celebration footage

Images:
- Chennai, nature, travel, celebration and retreat imagery from Pexels

The site serves the resulting files from the repository itself, so visitors do not load YouTube embeds or third-party video players.
